# AGENTS.md

A password reset service for a multi-tenant auth product. Each tenant owns its users and their reset tokens.

- `CODING_STANDARDS.md` holds the rules a reviewer enforces, with details in `docs/coding-standards/`.
- Features are RFCs in `docs/rfcs/`. A test names each behavior it covers by ID in its title.
- Run the tests with `bun test`. The repository has no dependencies to install.
